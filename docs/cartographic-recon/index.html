02 / WHAT SHOULD STAY TRUE

画风可以变，
地方之间的关系要留下来。

真正制作地图时，需要先确认地点在哪、道路怎样连接、哪些细节不能被画风改变。本案例保留历史检查结果与未通过项。

POSITION / 位置

地标回到正确街区。

修正地标所在街区，再检查是否破坏相邻地点的位置。

CONNECTION / 连接

交叉口需要对齐。

一条好看的线，不一定是一条真实可走的路。真实地图需要核查连通。

REVISION / 修改

补地点，保留原有关系。

补入五个要素时，同时检查原有九个地点和道路是否保留。

03 / FROM PLACE TO PAGE

让查证成为画图的一部分。

01 确定这张图的范围

街区、公园或一次散步。列出想留下的地点，说明地图服务什么用途。

02 留下地理底稿

记录地点来源、方位、道路连接和待核实部分，再决定画面怎样组织。

03 绘制，再对照检查

选择画风，把图与底稿逐项对照。修订时同时检查新内容和原有正确内容。

上方展示历史校验记录的匿名转述。自由图像生成不天然保证地理准确或拓扑不变。

04 / MAKE A PLACE YOUR OWN

下一张，可以是你熟悉的地方。

一段绿道，一个老街区，或一座常去的公园。给出范围、必标地点与画风参考，让地图有清楚的内容，也有自己的样子。

为什么没有展示原图？

原图包含私人生活区域的地名和道路，未纳入公开页面；案例只保留地点类别与校验结果。

这些状态代表什么？

pass 只适用于记录中的具体检查项。v2、v3 的整体状态仍为 pending，v4 为 fail；不能合并称作准确地图。

可以保证生成地图完全准确吗？

不能。实际工作必须核对地理关系；严格要求准确时，应使用固定可编辑底图，再生成装饰和画风。
