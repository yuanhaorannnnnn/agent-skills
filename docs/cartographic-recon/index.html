02 / WHAT SHOULD STAY TRUE

画风可以变，
地方之间的关系要留下来。

真正制作地图时，需要先确认地点在哪、道路怎样连接、哪些细节不能被画风改变。这里用虚构场景演示这些关系怎样被看见。

POSITION / 位置

西门仍在西岸。

建筑可以换画法，不能因为重新排版就被画到河流另一侧。

CONNECTION / 连接

小桥仍连接两岸。

一条好看的线，不一定是一条真实可走的路。真实地图需要核查连通。

REVISION / 修改

补地点，保留原有关系。

新增咖啡亭后，检查已有地点和道路有没有被无意移动或删掉。

03 / FROM PLACE TO PAGE

让查证成为画图的一部分。

01 确定这张图的范围

街区、公园或一次散步。列出想留下的地点，说明地图服务什么用途。

02 留下地理底稿

记录地点来源、方位、道路连接和待核实部分，再决定画面怎样组织。

03 绘制，再对照检查

选择画风，把图与底稿逐项对照。修订时同时检查新内容和原有正确内容。

上方 demo 用同一份 SVG 几何展示“保持关系”的交互概念。自由图像生成不天然保证地理准确或拓扑不变。

04 / MAKE A PLACE YOUR OWN

下一张，可以是你熟悉的地方。

一段绿道，一个老街区，或一座常去的公园。给出范围、必标地点与画风参考，让地图有清楚的内容，也有自己的样子。

这张纸上公园在哪里？

它是专门为展示页编写的虚构公园，没有真实坐标。不能用它导航或判断实际地理。

为什么先做示意图？

先确认作品展示、图层切换和修改对比是否清楚。下一版需要换入有来源底稿、经过核验的真实地图案例。

可以保证生成地图完全准确吗？

不能。实际工作必须核对地理关系；严格要求准确时，应使用固定可编辑底图，再生成装饰和画风。
