那些决定呢？

你已经解释过目标，纠正过误解，也否决过几个方案。事情还没做完，但这个会话已经太长了。

新 Agent 可以读代码。它却未必知道：为什么选了这条路，哪些办法试过了，还有哪一步没做完。

Passdown 从旧会话的原始记录中筛选相关内容，把这些判断与材料引用，一起交给接手的会话。

02 / PASSDOWN · 真实交接记录

换一个会话，
别让我再解释一次“档案袋”。

一个档案展示页做了多轮视觉调整。新会话需要接住设计约束，还要知道最新截图尚未验收。

原会话 / 用户原话节选
“那厚的，又光滑的，跟个字典似的，你觉得它像档案袋吗？”

省略口语开头；没有改写这段原话。

当时停在哪里？
“我不打开页面，给我发个架子的截图”

原会话发出截图；交接记录中没有用户对最新版外观的验收反馈。

新会话 / 实际交接输出节选

约束被带了过来。

“架藏材质应呈现薄纸袋、折边、纸纹和错落摆放，不能像光滑厚字典；视觉标准与卷内页面一致。”

未决状态也被带了过来。

“等待用户对最新架子截图的反馈；外观尚未获得明确验收。”

查看这次运行的边界

读取 1 个候选会话，提取 105 个回合，预算 8,000 tokens；22 个回合被舍弃、2 个被截断。重要信息仍需沿引用复核，不能称作“无损记忆”。

本次只读核对了页面、截图和已有校验记录，没有继续实现，也没有重跑历史测试。

这段 demo 要展示的：新会话拿到了“不能重犯什么”和“还不能宣称完成什么”。

脱敏：仅保留通用视觉需求；人物档案、项目名、会话 ID、用户名、本机路径及原始截图均未打包。

03

工作可以继续，
会话不必一直继续。

三个适合交接的时刻。

A

这个会话太长了。

开一个干净会话，把当前任务需要的决定和下一步带过去。

B

想换个 Agent 接手。

让接手者读到已经讨论过的取舍，沿着材料引用找到工作现场。

C

过几天，再回来。

按主题找回相关会话，恢复目标与进度，再核对文件的当前状态。

—

带走理解，保留出处。

原始记录留在原处

从来源会话读取。需要核对时，仍能回到那段对话。

文件通过引用连接

交接相关材料的位置与用途，工程文件仍由原工作区维护。

围绕当前任务筛选

在上下文预算内保留相关信息。交接摘要是继续工作的入口，关键结论仍需核对原件。

这是永久记忆吗？

Passdown 主要负责读取与筛选已有会话，恢复当前任务需要的上下文。长期知识维护仍由你的文件与知识管理方式承担。

会把所有历史都带过来吗？

不会。它按来源、主题和预算筛选对话。重要的实现细节、工具结果和状态，需要接手的 Agent 沿原始记录或文件引用继续核对。

这个 demo 可以连上我的会话吗？

不能。本页展示经过核实和脱敏的历史交接片段，展开操作只用于阅读，不会上传、读取或执行你的会话。
