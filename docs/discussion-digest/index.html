01 / MORE THAN A SHORTER THREAD

摘要很短，
却可能漏掉最重要的一句。

一个人提出方案，另一个人补充条件。讨论继续，有人改了主意，有些问题仍然悬着。

如果最后只剩一句“大家选了 JSBSim”，你就看不到：这是谁的偏好，实际合并了什么，还有什么没有落地。

把讨论的变化留下来。
让结论带着它的来路。
