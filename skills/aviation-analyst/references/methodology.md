# 航空小筑方法论 — 飞机照片推理框架

基于公众号「航空小筑」4 篇航空事故/识别分析文章提炼的通用推理方法论。
适用于 SkyScout LLM 视觉识别系统的 prompt 工程和知识库建设。

---

## 一、核心哲学

### 1.1 "推演一个逻辑自洽的场景"
不宣称找到真相，而是构建**内部一致、可被后续证据修正**的最合理解释。
> "按照老办法，推演一个逻辑自洽的场景和可能的原因，后面再慢慢修正或检验。"
> "以上均属猜测。就当是脑力锻炼了。"

### 1.2 承认信息局限性
> "仅凭这么几行字，加上两条视频，这信息量也太少了。"
> "靠这些就要逆推坠机事故，也无可能。"

信念度分级：
- 高置信：有明确物理证据支撑
- 中置信：逻辑自洽但缺少直接证据
- 低置信：推测，等待验证

## 二、四层分析框架

### Layer 1: 信息收集与验证

**多源交叉验证**
- 收集多方媒体报道，不依赖单一信源
- 区分事实与传言：标注"这是媒体报道，XX未确认" vs "有些媒体说XX，应为误传"

**量化数据提取**
- 距离（3800m、120m、207km）
- 时间（10:45am、9-12点时间窗）
- 坐标（经纬度、禁空区范围）
- 天气（温度、雨量、云量、风向风速）

**时空坐标建立**
- 时间锚点 + 空间锚点 → 统一参考系

### Layer 2: 空间重建

**方位确定**
- 利用阴影方向和坠机时间 + 当地纬度 → 太阳高度角 → 地理方位
- 利用地标对齐（跑道方向、禁空区坐标）

**多源图像对齐**
- 将不同视频帧、不同角度的碎片拼回统一空间坐标系
- 对齐阴影、对齐地标、对齐已知尺寸物体

**相对位置计算**
- 跳伞位置离坠机点水平距离、离表演区距离
- 由此推断飞机当时不在表演状态

### Layer 3: 特征识别与排除法

**结构性特征 → 确认机型**
- 平尾安装角调整机构形状 → KC-135
- 升降舵伺服调整片设计 → 波音 367-80 家族
- 双轮前架 + 切尖垂尾 + 空中加油管 → 排除多个型号
- 天线配置（L-150RWR 有无）→ 区分批次/年代

**损伤特征分类**
- 弹片伤：必有密集小孔和翻边，一眼可辨
- 擦撞伤：面状损伤，方向性
- 应力裂纹：由内向外崩开，沿翼肋等应力集中线
- 结构失稳：壁板褶皱 + 桁条断裂

**部件状态推理**
- 发动机甩出距离 + 地面扫痕 → 触地时高速运转 → 排除发动机故障
- 襟副翼完整脱落（非撕裂）→ 可能空中擦撞
- 尾锥平尾残骸无弹片伤 → 排除被击落

**排除法链条**
- 没有鸭翼 → 排除歼15S
- 双轮前架 + 切尖垂尾 + 加油管 → 排除苏27UBK/歼11BS/苏30MKK/MK2
- 无L-150天线 → 早于MKK → 只剩苏-30K
- 黄色条形标志位置 → 确认阿三的苏30K

### Layer 4: 因果链重构

**从结果反推原因**
```
残骸分布 → 飞机最后姿态 → 撞地前瞬间姿态 → 跳伞前姿态 → 故障原因
```

**物理约束推理**
- 1.7吨发动机不可能被油箱爆燃炸飞几十米 → 必须结构破坏 + 陀螺进动
- 发动机旋转 + 地面反作用力 → 尾喷管沿径向飞出
- 壁板向右扭转 → 垂尾受向右的力 → 飞行员蹬左舵

**飞行员行为推理**
- 碰撞 → 飞机抬头右转 → 飞行员推杆 + 左舵
- 推杆痕迹在左升降舵可见
- 左舵 → 垂尾承受向右力 → 结构失稳撕裂

**排除干扰假设**
- 阵风影响：烟柱高度 + 倾角 + 升起时间 → 风速仅 6.48km/h → 排除
- 尾流影响：视频中 02 姿态正常无摇摆 → 排除
- 密集编队失误：当时离开表演区非进入，间距正常 → 排除

## 三、AI 图像造假识别法

> 来源：《AI图识别实战练习》

### 识别层次（由浅入深）

**Level 1: 标志性图案检查（零基础可用）**
- 机徽、军徽等标志性符号是否变形、错位
- AI 处理的典型特征：图案扭曲、边缘模糊

**Level 2: 涂装知识检查**
- 机编号位置是否符合该国/该军种规范
- 涂装颜色和位置是否与已知照片一致

**Level 3: 机型特征检查（需要专业知识）**
- 声称的型号与实际展示的特征是否一致
- 关键识别点是否具备（破风锥、后视镜、备用空速管、加油管凹槽）

**Level 4: AI 增减细节识别**
- AI 莫名其妙删除的细节：破风锥、后视镜、空速管、凹槽
- AI 莫名其妙增加的细节：管路、平显、白色整流体、小弹翼、锈迹、蒙皮接缝线
- AI 增加物体的比例问题：导弹/挂架尺寸比例失调

**Level 5: 精确溯源**
- 通过排除法确定原图真身
- 对比已知真机照片的关键特征和涂装标记

## 四、适用到 SkyScout 的视觉识别

### 4.1 民航机识别层级

**大类识别（窄体/宽体/大型）**
- 机身粗细比例
- 发动机数量和位置
- 整体尺度感

**具体型号识别**
| 观察点 | A320 系列 | B737 系列 | A330 | B777 | B787 | A350 | A380 | B747 |
|--------|----------|----------|------|------|------|------|------|------|
| 翼尖形状 | 鲨鱼鳍上翘 | 分叉双翘 | 小翼上翘 | 无翼尖 | 优雅上弯 | 渐收 | 无翼尖 | 翼尖小翼 |
| 驾驶舱窗 | 标准 | 标准 | 标准 | 标准 | 圆滑 | 黑框墨镜 | 标准 | 驼峰上 |
| 发动机数 | 2 | 2 | 2 | 2 | 2 | 2 | 4 | 4 |
| 起落架 | 常规 | 常规 | 常规 | 6轮一排 | 常规 | 常规 | 多轮 | 多轮 |
| 机身特殊 | — | — | — | 最粗双发 | 大窗 | — | 双层 | 驼峰 |

**航空公司识别**
- 尾翼标志图案和颜色
- 机身涂装主色调
- 中文航司特征：
  - 红色凤凰 → 国航
  - 蓝色木棉花 → 南航
  - 白底红字 → 东航
  - 红色大鹏 → 海航
  - 红蓝绿条纹 → 厦航

**注册号识别**
- 中国：B-xxxx（机身尾部或机翼上方）
- 美国：Nxxxxx
- 位置：机尾垂直面、后机身、机翼上表面

### 4.2 推理叙事风格（适用到 reasoning 输出）

**"侦探推理"叙事模板：**
> 首先看 XXX 特征 → 这说明是 YYY 类型 → 进一步观察 ZZZ 细节 → 排除了 AAA、BBB 可能性 → 最终锁定 CCC → 和你看到的一样吗？

**关键语调：**
- 邀请性而非断言性："可能是"、"从XX来看"
- 教方法而非给答案："下次你也可以看看XX"
- 惊喜感："你知道吗？它的窗户比其他飞机大30%！"
- 验证性："和你看到的一样吗？"

## 五、进阶推理技术（来自 184 篇文章的系统扫描）

### 5.1 系统级推理

**液压/机械系统故障矩阵**
- 绘制系统依赖图（A/B/备用液压 → 各操纵面）
- 建立逻辑矩阵：观察到的状态 × 可能的故障点 → 找矛盾
- 当矩阵出现矛盾 → 非机械原因（人为因素、外部破坏）
- 案例：7C2216 的襟翼/扰流板/反推状态与液压系统矩阵矛盾 → 人为因素可能性上升

**反推/机械结构约束推理**
- 查技术手册获取精确参数（液压压强 3000PSI → 锁定力 2720kg）
- 物理约束排除假设（地面摩擦力不可能拉开反推）
- 结论：即使意外展开，机械联动保证阻流门工作

### 5.2 物理计算作为证据

**运动学重建**
- 抛物线公式反推：7s 自由落体 = 240m，实际 600m → 有 51m/s 垂直分量 → 不是双发停车
- 平均速度异常：全程 7min/31km = 266km/h < 起飞速度 → 大部分时间在垂直运动
- 发动机甩出距离 + 质量 → 排除爆燃 → 必须是结构破坏 + 陀螺进动

**摩擦力/受力分析**
- 高速滑行时（300+ km/h）机翼仍有升力 → 地面正压力不够 → 摩擦力不够
- 1.7 吨发动机被甩出几十米 → 计算所需能量 → 排除油箱爆燃

### 5.3 天气作为证据

**METAR 报告 vs 口头说法**
- 官方说"浓雾"→ 查 METAR：能见度 3500m，轻雾 BR → 已满足目视着陆标准
- "人的感官比不上科学数据"

**现场环境推断**
- 浓烟竖直向上 → 微风/无风（排除风切变）
- 树叶不动 → 风速极低
- 烟柱倾角 + 升起时间 → 计算实际风速（6.48km/h vs 传说的 47km/h）
- 季节 + 地点 → 排除大型候鸟（非迁徙季节）

### 5.4 损伤方向性分析

**弹道/冲击方向推理**
- 开口方向判断冲击来源：左侧→右 = 来自左方的外力
- 贯穿孔方向一致 → 单一来源
- 砂石损伤方向 vs 破片损伤方向 → 区分坠地伤和空中伤
- 无血迹 → 排除撞鸟

**残骸空间分布推理**
- 残骸散落四周、无地面摩擦痕迹 → 空中已解体，落叶飘
- 发动机 + 尾喷管相对位置 → 发动机旋转 + 地面冲击 → 尾喷管径向飞出
- 左右翼 L 型折叠 → 斜反扣姿态撞地

### 5.5 时间轴重建

**多源时间锚点对齐**
- GPS 信号时间戳 + 乘客聊天记录时间 + 官方报告时间 → 建立事件时间线
- 阳光角度 + 飞机航向 + 时间 → 确定视频拍摄阶段（撞鸟发生在复飞而非进近）
- 建筑物天花板 → 排除海上 → 确认复飞阶段

**处置时间压力分析**
- 撞鸟到坠毁仅 10 分钟
- 正常复飞程序需要排队等待重新进近（不可能掉头反向着陆）
- 未挂 7700 代码 → 未宣布紧急状态
- 时间 + 程序要求 → 机组在极端压力下可能遗漏操作

### 5.6 失速/气动分析

**视频帧分析的精确方法**
- 逐帧截图（< 2 秒内多帧）
- 机身纵轴线绘制（红线连接机头→机尾）
- 俯仰角变化检测（机尾突然下沉 = 迎角剧增）
- 速度矢量无变化 + 俯仰角变化 → 迎角超过临界

**失速-滚转机制**
- 平直翼失速 → 机翼自转 → 急剧滚转
- 飞行员下意识压反杆 → 副翼下偏 → 加剧失速侧气流分离 → 加速滚转
- 这与"机械故障"的表现不同

### 5.7 人为因素分析

**情景意识丢失判断**
- 双机互相进入对方视野盲区
- 坡度变化导致高度差 → 航线投影相交
- 在未确认友机位置时继续机动

**空间定向障碍**
- 视错觉机制：环境光线强烈对比 → 大脑优先采纳视觉而非身体感觉
- 仪表矛盾 → 不知道该信哪个 → 飞行员心态崩溃
- 对比案例：僚机引导成功返场（爆风挡后重伤仍迫降）→ 承压能力差异

### 5.8 维护/机务链推理

**维修状态追溯**
- D 检后首飞 → 发动机会被拆下油封再装回 → 性能应与检前一致
- 轮子是常换件，与机龄无关 → 差错通常是机务操作失误
- 结构老化不可怕，可怕的是老化未被发现

### 5.9 外部因素推理

**误击可能性判断框架**
- GPS 被干扰/信号丢失 → 二次雷达无显示 → 防空单位无法识别
- 军用机场距民用机场 17km → 低空低速不明目标 → 误判为无人机
- 残骸孔洞方向 + 爆炸位置 → 排除坠地损伤

**协同困境**
- "我怎么知道你看到的就是我看到的？"
- 民航/空管和防空的雷达信息不互通 → 误击窗口

## 六、验证文化："Bingo!"

作者大量文章标题以"Bingo!"、"全中"、"推测证实"开头，体现了其方法论的核心验证循环：

```
推测 → 等待官方报告/后续信息 → 对比验证 → 记录正确/错误 → 修正方法论
```

**高命中率领域**（根据 17 篇验证文章统计）：
- 损伤机制判断（弹片伤 vs 擦撞伤）— 几乎全中
- 飞控故障 vs 发动机故障区分 — 高命中
- 空中解体 vs 地面解体 — 全中
- 人为因素识别 — 中高命中

**易出错领域**：
- 撞地前瞬间姿态（F-35B "判断错误，触地时没反扣"）
- 发动机是否仍运转（有时被残骸误导）

## 七、AI 视觉识别 Prompt 应该具备的能力

基于以上方法论，SkyScout 的 LLM 视觉识别应该：

1. **先观察，再推理，最后下结论**（不要先下结论再找理由）
2. **分批列出观察到的特征**（翼尖、发动机、机身、涂装、注册号）
3. **用排除法缩小范围**（不是 A 因为缺少特征 X，不是 B 因为 Y 不对）
4. **给出置信度**（高/中/低，并解释为什么不确定）
5. **用侦探叙事语气**（面向 6-12 岁儿童，邀请孩子一起验证）
6. **标注"如果...那么..."的假设链**（让推理过程可被检验）
